================================================================================
QUERY FLOW: MULTI-SIGNAL RAG RETRIEVAL
================================================================================

┌───────────────────────────────────────────────────────────────────────────┐
│ STEP 1: Vector Similarity Search (pgvector)                               │
├───────────────────────────────────────────────────────────────────────────┤
│                                                                            │
│   SELECT id, error_type, error_message,                                   │
│          1 - (embedding <=> :query_embedding) AS vector_similarity        │
│   FROM sentry_issues                                                       │
│   WHERE embedding IS NOT NULL                                              │
│   ORDER BY embedding <=> :query_embedding                                  │
│   LIMIT 50;                    -- Candidate set                            │
│                                                                            │
└───────────────────────────────────────────────────────────────────────────┘
                                   │
                                   ▼
┌───────────────────────────────────────────────────────────────────────────┐
│ STEP 2: Enrich with Metadata Signals                                      │
├───────────────────────────────────────────────────────────────────────────┤
│                                                                            │
│   SELECT vm.id, vm.error_type, vm.vector_similarity,                      │
│          es.release_recency_score,                                         │
│          es.ownership_match_score,                                         │
│          es.alert_frequency_score,                                         │
│          es.replay_impact_score,                                           │
│          es.tag_overlap_score,                                             │
│          -- Final composite score                                          │
│          (vm.vector_similarity * 0.40 +                                    │
│           es.release_recency_score * 0.15 +                                │
│           es.ownership_match_score * 0.15 +                                │
│           es.alert_frequency_score * 0.10 +                                │
│           es.replay_impact_score * 0.10 +                                  │
│           es.tag_overlap_score * 0.10) AS final_score                      │
│   FROM vector_matches vm                                                   │
│   LEFT JOIN enrichment_signals es ON vm.id = es.issue_id                  │
│   ORDER BY final_score DESC                                                │
│   LIMIT 10;                    -- Top results                              │
│                                                                            │
└───────────────────────────────────────────────────────────────────────────┘
                                   │
                                   ▼
┌───────────────────────────────────────────────────────────────────────────┐
│ STEP 3: Return Ranked Results to LLM                                      │
├───────────────────────────────────────────────────────────────────────────┤
│                                                                            │
│   • Top 10 issues sorted by final_score                                   │
│   • Includes enrichment context:                                          │
│     - Release info (suspect commits)                                      │
│     - Performance data (problem spans)                                    │
│     - Ownership (team assignments)                                        │
│     - Alert history                                                       │
│     - Session impact                                                      │
│                                                                            │
│   LLM uses this rich context for better analysis!                         │
│                                                                            │
└───────────────────────────────────────────────────────────────────────────┘
