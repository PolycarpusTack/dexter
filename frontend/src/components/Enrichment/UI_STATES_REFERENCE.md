Quick visual reference for all component states and interactions.

## FreshnessPill States

### Fresh (< 5 min)
```
┌──────────────────────────┐
│ ✓ 2m ago                 │  Green badge
└──────────────────────────┘
```

### Recent (5-30 min)
```
┌──────────────────────────┐
│ 🕐 15m ago               │  Blue badge
└──────────────────────────┘
```

### Stale (30 min - TTL)
```
┌──────────────────────────┬─────┐
│ 🕐 45m ago              │  ↻  │  Yellow badge + Refresh button
└──────────────────────────┴─────┘
```

```
┌──────────────────────────┬─────┐
│ ⚠ 2h ago               │  ↻  │  Orange badge + Refresh button
└──────────────────────────┴─────┘
```

```
│ ⚠ Failed to fetch       │  ↻  │  Red badge + Refresh button
```

## Color Coding Reference

### Freshness Pills
- 🟢 Green: Fresh (< 5 min)
- 🔵 Blue: Recent (5-30 min)
- 🟡 Yellow: Stale (30 min - TTL)
- 🟠 Orange: Very Stale (> TTL)
- 🔴 Red: Failed

### Timeline Events
- 🔵 Blue: Navigation events
- 🟣 Purple: HTTP requests
- 🟠 Orange: Console logs
- 🔴 Red: Errors, Critical path
- ⚪ Gray: Default events

### Performance Indicators
- 🟢 Green: < 500ms
- 🔵 Blue: 500-1000ms
- 🟠 Orange: 1000-2000ms
- 🔴 Red: > 2000ms

### Confidence Levels
- 🟢 Green: High (≥ 80%)
- 🔵 Blue: Medium (60-79%)
- 🟡 Yellow: Low (40-59%)
- 🔴 Red: Very Low (< 40%)

## Responsive Breakpoints

### Desktop (> 1200px)
- Full tab list visible
- Drawer: 600px wide
- Timeline: Full height with scroll

### Tablet (768px - 1200px)
- Tab list scrollable horizontally
- Drawer: Full width
- Timeline: Condensed view

### Mobile (< 768px)
- Tab list: Dropdown
- Drawer: Full screen
- Timeline: Stack view
- Touch targets: 44x44 min
